# 최문봉 · AI Engineer Portfolio

데이터 구축부터 학습, 평가, 배포까지 직접 해 온 AI 엔지니어 포트폴리오입니다.

- 에티오피아 사진측량 기반 주택특성 DB 구축 (건물 F1 0.924)
- 7개 분할 모델 비교와 데이터 중심 성능 개선
- SAM 2.1 기반 QGIS 반자동 라벨링·검수와 학습데이터 생성
- 연구: 고려대 MILab 제1저자 논문 3편 (KCC 2024 우수논문상)

페이지 보기: GitHub Pages 주소에서 확인하세요.

자동 라벨링 이미지: 2026-11-10 플러그인의 SAM 2.1 추론 코드에 원본 영상의 다른 포함 클릭 지점 `(350, 302)`를 지정해 재실행했습니다. 오른쪽 도로변 건물 1개의 경계 후보를 확인하고 별도 GeoPackage에 저장했습니다. 원본 해상도의 영상과 작은 확대 보기 위에 저장된 폴리곤을 채움 없는 SVG 윤곽선으로 표시하며, 경계 표시를 켜고 끄며 원본 지붕을 비교할 수 있습니다. RGB 밴드 순서와 EPSG:20137 좌표계를 유지했고 영상 픽셀이나 모델의 경계를 보정하지 않았습니다. 이 예시는 분류 정확도나 전체 장면 자동 탐지 성능을 나타내지 않습니다. 시각자료는 `assets/labeling/`에 있습니다.
