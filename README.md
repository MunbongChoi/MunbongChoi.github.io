## 2026.10.30 회의자료 반영

`20261030_부동산원 회의.pptx`의 모델 비교·데이터 개선·공간 연계 내용을 반영했습니다. 입력 전처리·증강·데이터·분할·후처리는 공통이고 배치 크기·학습률은 모델별로 조정했습니다. 공간 홀드아웃은 train 873 / val 75 / test 131이며 완충 51타일을 제외했습니다. 무중첩에서 온전하게 포함되지 않은 건물은 9,289/64,887동(14.3%)이고, 25% 중첩으로 온전한 포함률이 85.7%에서 99.9%로 증가했습니다.

모델 비교에서 선택한 W48과 D-LinkNet+를 고정한 데이터 개선 실험의 수치를 구분합니다. 도로 연결 상태와 건물 위치 보정 전후 분류는 정답 대조 정확도가 아닙니다. 기본 장면 추출 67,465동과 공간 연계 실험 67,507동은 별도 집계입니다. 필지에서 상속한 POI는 개별 건물 용도 정답이 아닙니다.

공개한 지도 2장은 자료의 31·41쪽 원본 삽입 이미지입니다. 원본 PPT는 변경하거나 공개하지 않았습니다. 이미지 출처·슬라이드 번호·해시는 `assets/ppt-20261030/provenance.json`에 기록했습니다.

## 실제 자동 라벨링 예시

붉은 지붕의 다른 건물 `(258, 204)`에서 SAM 2.1 Tiny 추론을 다시 실행했습니다. 첫 번째 후보에 원본 픽셀 기준 DP 5 px를 적용해 정점이 100개에서 4개로 줄었습니다. 네 모서리는 알고리즘이 반환한 값이며 수동 이동·사각형 강제 변환을 하지 않았습니다. 폐합용 중복 끝점은 정점 수에서 제외합니다. 화면의 `DP 적용`을 꺼 같은 후보의 원본 경계와 비교할 수 있습니다.

이 영상은 0.30 m/px이므로 5 px는 1.50 m의 도형 단순화 허용오차입니다. 위치 정확도나 건물 외곽의 실측 오차를 나타내지 않습니다. 플러그인 기본값은 1 px, 설정 범위는 0~5 px입니다. 이 예시는 화면에서 선별한 모델 제안이며 검수·확정된 정답이나 전체 장면 성능 평가가 아닙니다.

원본과 DP 결과를 별도 GPKG 레이어로 저장하고 새로 열어 도형·EPSG:20137·정점 수 일치를 확인했습니다. 원본 RGB 영상은 그대로이며 확대 이미지는 원본 픽셀의 96×96 crop입니다. 이전 예시에서 설치된 플러그인의 실제 추론·미리보기·저장 경로도 검증했습니다. 새 예시의 기록은 별도 보관하며 웹 이미지는 `assets/labeling/`에 있습니다.
