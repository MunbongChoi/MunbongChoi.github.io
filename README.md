# 최문봉 · AI Engineer Portfolio

데이터 구축부터 학습, 평가, 배포까지 직접 해 온 AI 엔지니어 포트폴리오입니다.

- 에티오피아 사진측량 기반 주택특성 DB 구축 (건물 F1 0.924)
- 7개 분할 모델 비교와 데이터 중심 성능 개선
- SAM 2.1 기반 QGIS 반자동 라벨링·검수와 학습데이터 생성
- 연구: 고려대 MILab 제1저자 논문 3편 (KCC 2024 우수논문상)

페이지 보기: GitHub Pages 주소에서 확인하세요.

자동 라벨링 이미지: 10개 건물의 결과를 비교해 선정한 왼쪽 붉은 지붕 건물 `(81, 275)`에 SAM 2.1 추론과 더글라스–피커(DP) 단순화를 다시 실행했습니다. 같은 SAM 경계의 정점 수는 원본 80개, 허용오차 1 px에서 19개, 2 px에서 6개입니다. 폐합용 중복 끝점은 제외합니다. 화면은 2 px 적용 결과를 기본으로 보여주며 `DP 적용`을 꺼 원본 경계와 비교할 수 있습니다.

DP는 원본 영상의 픽셀 좌표에서 수행한 뒤 원본 좌표계로 복원합니다. 이 예시의 2 px는 0.60 m이며, 도형 단순화 허용오차입니다. QGIS 플러그인 기본값은 1 px이고 설정에서 0~5 px를 지정합니다. 설치된 플러그인의 실제 추론·미리보기·GPKG 저장을 검증했으며, 표시한 경계는 저장 결과와 일치합니다. 원본 후보와 DP 결과를 별도로 보관하고, 원본 영상의 RGB 값과 EPSG:20137 좌표계는 유지했습니다. 외곽선이 양호한 사례를 선별한 예시이며, 분류 정확도나 전체 장면 자동 탐지 성능을 나타내지 않습니다. 시각자료는 `assets/labeling/`에 있습니다.
