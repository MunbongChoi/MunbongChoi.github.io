# 최문봉 · AI Engineer Portfolio

위성영상·음향·음악 생성 프로젝트를 문제, 해결 방법, 선택 이유와 확인한 결과 중심으로 정리한 포트폴리오입니다.

공개 페이지: https://munbongchoi.github.io/

## 대표 사례

1. **공간정보 AI** — 모델 비교 이후 반복되는 건물 경계 오류를 점검하고 정답 벡터화, 타일 중첩·크기와 객체 단위 평가를 개선했습니다. D-LinkNet+ 고정 실험의 IoU 0.817 → 0.8586, F1 0.899 → 0.9239와 모델 비교의 W48 채택을 구분합니다.
2. **음향 연구** — 소리 질의·Wave-U-Net을 이용한 목표 소리 추출과 Attention Gate 기반 BioCPPNet의 특징 선택 경로를 독립 사례로 구성했습니다. 논문 제목·발표 이력·KCC 2024 우수논문상은 공식 연구실 목록과 연결합니다.
3. **음악 생성** — Muzig의 장비·모델 가용성 제약, 키워드별 평가와 Weak / Strong 모델 라우팅의 선택 이유를 정리했습니다.
4. **검수·서비스 도구** — SAM·DP 라벨링, Web GIS, 개발후보지 분석과 변화탐지 검토의 기능을 실제 작업 문제와 연결했습니다.

상세 모델표·공간 연계 규칙·추가 검증 계획은 펼쳐보기로 보관합니다. 외주 라벨 검수 파이프라인과 후속 데이터 구축 제안은 설계·제안 상태로 표시합니다. 음향과 음악 생성 도식은 구조 설명용 개념도입니다.

## 기술별 문제 해결

포트폴리오에 등장하는 68개 기술·방법을 7개 분야로 정리했습니다. 각 항목에 **문제 / 적용 방법 / 선택 이유**를 작성하고 구현·비교 실험·연구·설계 범위와 관련 사례를 연결했습니다. 기존 기술명 나열 영역을 교체했으며 기술명·문제 검색과 전체 펼치기, 모델표에서 해당 기술로 이동하는 링크를 제공합니다.

기술별 본문과 별도로 기계 판독 가능한 기록은 `assets/case-studies/technology-decisions.json`에 보관합니다. D-LinkNet+, R50, HRNet, W48, SegFormer(PVTv2 구성), Mask2Former와 P2PFormer는 적용 목적과 비교·채택 판단을 개별 설명합니다. YOLO·TensorFlow의 일반적인 선택 기준은 해당 기술 정의 및 경력자료 범위로 구분합니다. 모든 기술을 최종 서비스에 동시에 채택한 것으로 서술하지 않습니다.

## 근거와 범위

전문 경력자료, 공개 논문 정보 및 연구실 발표·수상 목록을 근거로 서술했습니다. 원본 경력자료나 개인정보는 웹에 올리지 않습니다. 출처 제목·해시·공개 링크와 도식 성격은 `assets/case-studies/provenance.json`에 기록합니다.

기존 지도·제품 화면과 비교 슬라이더, PPT 출처·집계 범위 및 자동 라벨링 경계를 유지합니다. 공간 연계 상태 집계는 정답 대조 정확도가 아니며 필지에서 상속한 POI는 개별 건물 용도 정답이 아닙니다.

자동 라벨링은 실제 SAM 2.1 Tiny 후보 `(258, 204)`에 원본 픽셀 기준 DP 5 px를 적용한 사례입니다. 정점은 100개에서 4개로 줄었으며 수동 이동이나 사각형 강제 변환을 하지 않았습니다. 5 px는 이 영상의 1.50 m 도형 단순화 허용오차이며 위치 정확도 지표가 아닙니다. 원본 RGB·EPSG:20137·96×96 확대 crop과 원본/DP 경계 전환을 보존합니다. 플러그인 기본값은 1 px, 설정 범위는 0~5 px입니다.

PPT 지도는 `assets/ppt-20261030/`의 원본 삽입 이미지이며 출처·슬라이드 번호·해시는 기존 `provenance.json`을 유지합니다. 기본 장면 67,465동과 공간 연계 실험 67,507동은 별도 집계입니다.
